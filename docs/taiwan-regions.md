# 台灣北中南東分區

「北中南」**沒有唯一定義**。這類題目的難點是先決定用哪一個定義，查表本身不難。下面整理官方來源與彼此的差異，`tools/tw.py` 的 `region(縣市, scheme)` 已經內建這些分法。

## 決策規則

1. 題目或資料有附定義 → 照它，不要用下面的表。
2. 資料出自某機關（看檔名、欄位、出處）→ 用該機關的分法。
3. 以上都沒有 → 用預設 `ndc`，並且只要答案會變，就在「歧義」列出 `ndc_islands`、`circle7` 的答案。
4. 金門、連江要不要算進來，要另外判斷：主計總處人力資源調查的範圍只有「臺灣地區」20 縣市，不含金馬。題目若是「全國」，而資料沒有金馬，要寫進假設。

## 定義一：國發會／主計總處（預設，`scheme="ndc"`）

| 區域 | 縣市 |
|---|---|
| 北部 | 臺北市、新北市、基隆市、桃園市、新竹市、新竹縣、宜蘭縣 |
| 中部 | 臺中市、苗栗縣、彰化縣、南投縣、雲林縣 |
| 南部 | 臺南市、高雄市、嘉義市、嘉義縣、屏東縣、澎湖縣 |
| 東部 | 花蓮縣、臺東縣 |
| 金馬 | 金門縣、連江縣（統計上歸「福建省」，不在四大區域內） |

來源：
- 國發會《都市及區域發展統計彙編》區域定義
- 主計總處「人力資源調查縣市別失業率」（https://data.gov.tw/dataset/6640）的欄位分組與上表一致

最容易搞錯的地方：**宜蘭屬北部**（不是東部）、**苗栗、雲林屬中部**、**嘉義屬南部**、**澎湖屬南部**（不是另列離島）。

## 定義二：北中南東＋離島（`scheme="ndc_islands"`）

同定義一，但把澎湖、金門、連江合為「離島」。題目出現「外島」或「離島」時最常這樣分。這是常見的寫法，不是單一機關的統計定義，採用時要寫進假設。

**鄉鎮層級的離島**：教育部《離島地區學生保送高級中等以上學校辦法》把離島地區定義為澎湖縣、金門縣（含烏坵鄉）、連江縣、臺東縣綠島鄉、臺東縣蘭嶼鄉、屏東縣琉球鄉。如果資料細到鄉鎮、題目又問到離島，綠島、蘭嶼、琉球要不要從臺東縣、屏東縣剔除，要列為歧義。《離島建設條例》第 2 條只寫「與臺灣本島隔離屬我國管轄之島嶼」，沒有逐一列舉。

## 定義三：七大區域生活圈（`scheme="circle7"`）

出自行政院 99 年 2 月核定的「國土空間發展策略計畫」：

北北基宜｜桃竹苗｜中彰投｜雲嘉南｜高屏｜花東｜澎金馬

跟定義一不同的地方：**苗栗**在桃竹苗（定義一屬中部）、**雲林**在雲嘉南（定義一屬中部）、**澎湖**在澎金馬。

同一份計畫也提到「北中南三大生活圈」，但沒有查到逐縣市的官方對照表。不要自行推定；題目用到時上網查原文。

## 不要用的分法

國發會「六大區域產業」（例如北北基宜首都圈、桃竹苗大矽谷、嘉南高屏大南方新矽谷）是產業政策用語，不是統計分區。除非題目明確指定，否則不要用。

## 縣市改制

| 日期 | 改制 |
|---|---|
| 2010-12-25 | 臺北縣 → 新北市；臺中縣市合併 → 臺中市；臺南縣市合併 → 臺南市；高雄縣市合併 → 高雄市 |
| 2014-12-25 | 桃園縣 → 桃園市 |

舊資料可能同時有「臺中市」和「臺中縣」兩欄（主計總處的失業率資料集就是這樣），跨年比較前要先合併。`normalize_county()` 預設把舊名併入新名；要保留舊名就用 `merge_old=False`。

## 現場查證

有網路時可以用 WebFetch 再確認：https://data.gov.tw/dataset/6640 的「主要欄位說明」依地區分組列出縣市，欄位順序就是分組。
